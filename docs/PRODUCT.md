# PromptForge R0 Product Contract

## North-star
Prompt Improvement Rate: the percentage of remaining skill gap closed between first and best subsequent attempt.

## Core loop
Measure → Teach → Practice → Re-attempt → Measure.

## R0 acceptance criteria
1. A stranger can start the skill test without an account.
2. Ten questions are answerable on mobile.
3. Prompt Coach produces a 0–100 score with seven dimension scores.
4. Final score is calculated by application code, not selected by the LLM.
5. Feedback identifies concrete missing elements and explains why they matter.
6. User can rewrite and re-score a prompt.
7. Daily challenge uses the same evaluator with task context.
8. Progress records scored events and shows change over time.
9. API keys never reach the browser.
10. Requests are rate-limited and input lengths are bounded.
